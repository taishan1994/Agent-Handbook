# SoK：Agentic Skills——超越工具调用，重新定义LLM智能体的能力范式
在大语言模型（LLM）智能体从单轮问答走向多步自主执行的今天，**工具调用**早已成为标配，但智能体始终面临一个核心困境：面对重复任务，每次都要从零推导执行策略，无法沉淀可复用的过程性知识。2026年2月发布的论文**《SoK: Agentic Skills — Beyond Tool Use in LLM Agents》**，首次以**智能体技能（Agentic Skills）**为核心视角，系统性梳理了LLM智能体的能力封装、生命周期、设计范式与安全治理，为智能体从“临时规划”走向“持久技能化”提供了完整理论框架。

这篇论文并非提出单一算法，而是一份**LLM智能体技能体系的知识系统化（SoK）报告**，清晰界定了智能体技能的本质、边界、应用与风险，成为当前智能体架构设计的重要参考。

## 一、核心定义：什么是真正的「智能体技能」？
论文给**智能体技能**做了严谨的形式化定义：**S=(C, π, T, R)**，这是区别于工具、计划、记忆的关键，也是技能成为智能体“过程性记忆”的核心。
1. **C（适用条件）**：判断当前场景是否适合调用该技能的逻辑，解决“什么时候用”。
2. **π（执行策略）**：技能的具体实现，可自然语言、代码、策略模型或混合形式，解决“怎么做”。
3. **T（终止条件）**：明确技能完成/失败的标准，解决“什么时候停”。
4. **R（调用接口）**：标准化的元数据与调用契约，支持程序化调用，解决“怎么被调用”。

论文明确区分了**技能与相关概念**：
- **工具**：原子化API，无决策逻辑；技能可调用工具，自带多步骤与适用判断。
- **计划**：一次性推理框架，不可复用、不可直接执行；技能是持久化、可调用模块。
- **记忆**：存储事实与观测；技能是“怎么做”的过程性知识，而非“是什么”的陈述性知识。

简单来说，**工具是基础能力，计划是临时思路，技能是可复用、可治理、可组合的标准化工作流**。

## 二、智能体技能的完整生命周期
论文将技能从无到有、从使用到迭代的全过程，划分为**7个核心阶段**，形成闭环：
1. **发现**：识别重复任务模式，确定值得封装为技能的场景。
2. **实践与精炼**：通过试错、反思优化技能策略，提升可靠性。
3. **提炼**：将执行轨迹压缩为稳定通用的(C, π, T, R)模块。
4. **存储**：存入技能库，做索引、版本管理，支持高效检索。
5. **检索与组合**：运行时筛选技能，拼接成复杂工作流。
6. **执行**：在沙箱/权限控制下运行技能策略。
7. **评估与更新**：监控效果，修复、迭代或淘汰失效技能。

这个生命周期打破了“技能是静态模块”的认知，强调**技能是持续进化的系统组件**，而非一次性封装。

## 三、七大设计模式：技能落地的主流架构方案
基于现有系统，论文总结了**7种技能设计模式**，覆盖从人工管控到完全自主进化的全谱系：
1. **元数据驱动渐进式加载**：先展示精简元数据，调用时再加载完整指令，节省上下文（代表：Claude Code、Semantic Kernel）。
2. **代码即技能**：技能是可执行脚本，确定性强、可测试（代表：Voyager、CodeAct）。
3. **工作流强制执行**：固定执行步骤，约束智能体行为，提升可靠性（代表：TDD智能体、LATS）。
4. **自进化技能库**：自主生成、验证、更新技能，适配新任务（代表：Voyager、CRADLE）。
5. **自然语言+代码混合宏**：兼顾人类可读性与机器可执行性（代表：Claude技能、ReAct）。
6. **元技能**：创造/修改技能的技能，实现技能库自主扩容（代表：Self-Instruct、CREATOR）。
7. **插件/市场分发**：技能打包为可分发包，生态化扩展（代表：GPT Store、ClawHub）。

这些模式并非互斥，实际系统常组合使用（如市场分发+元数据加载+混合实现），覆盖了当前主流智能体框架的核心架构逻辑。

## 四、双重分类体系：技能的内在属性与应用边界
论文提出**正交的双重分类法**，清晰描述“技能是什么、能用在哪”：
### 1. 表示形式（怎么编码）
- 自然语言技能：易编写、易审计，但存在歧义。
- 代码技能：确定性高、可测试，依赖沙箱执行。
- 工具宏：结构化工具调用序列，介于自然语言与代码之间。
- 策略型技能：微调模型实现，隐式但能捕捉复杂行为。
- 混合表示：结合多种形式，平衡灵活与可靠。

### 2. 应用范围（用在什么场景）
覆盖**单工具、多工具编排、网页交互、桌面/系统操作、软件工程、机器人**六大领域，其中**医疗、制造等基础模型预训练数据薄弱的领域**，技能提升效果最显著（SkillsBench数据显示最高+51.9%）。

## 五、安全与治理：技能化带来的全新风险
技能化让智能体更强大，也引入了**全新攻击面**，论文结合真实案例**ClawHavoc攻击**做了深度分析：
### 核心威胁
- 元数据投毒：误导检索机制调用恶意技能。
- 技能载荷攻击：代码/自然语言中隐藏恶意指令，窃取API密钥、加密货币钱包、浏览器凭证。
- 供应链风险：技能市场成为恶意代码传播渠道（ClawHub曾有36.8%技能含安全漏洞）。
- 权限越界：低权限技能诱导升级权限，或跨租户数据泄露。

### 治理方案
论文提出**四层信任模型**：元数据仅可见→指令访问→监督执行→自主执行，逐级开放权限；同时配套**沙箱执行、源码签名、依赖审计、持续监控、版本锁定**等供应链治理手段，弥补技能市场的安全短板。

## 六、关键结论：技能质量决定智能体性能
论文基于**SkillsBench基准**得出颠覆性结论：
1. **人工精选技能**：平均提升智能体任务成功率**16.2个百分点**，小模型+精选技能可超越无技能大模型。
2. **自主生成技能**：平均降低成功率**1.3个百分点**，无验证的自主生成会引入错误启发式。
3. **技能复杂度有最优解**：2-3个模块的精简技能效果最好，过度详细的技能反而拖累性能。

这直接点明：**技能的价值不在“有”，而在“精”**，规模化生成不如高质量 curated。

## 七、未来方向：智能体技能的未决挑战
论文最后指出了五大研究前沿：
1. **可验证的自主技能生成**：解决自生成技能质量不可控问题。
2. **无监督技能发现**：摆脱人工课程/演示，自主识别技能边界。
3. **跨表示形式化验证**：让自然语言技能也能像代码一样被安全审计。
4. **环境漂移下的鲁棒性**：应对API、界面变化导致的技能失效。
5. **治理经济学与责任界定**：明确技能市场中作者、平台、用户的责任。

## 结语
这篇SoK论文的核心价值，是把**Agentic Skills**从模糊概念变成**可定义、可设计、可治理、可评估**的标准化体系，终结了“工具=技能”的认知误区。它证明：LLM智能体的下一阶段竞争，不再是模型大小，而是**技能体系的完善度、可靠性与安全性**。

对于开发者、研究者与从业者而言，这篇论文既是**智能体技能设计的手册**，也是**安全治理的指南**，为构建真正自主、可靠、可规模化的LLM智能体，指明了清晰路径。
