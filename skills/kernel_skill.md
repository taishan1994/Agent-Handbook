# KernelSkill：一种用于GPU内核优化的多智能体框架

## 摘要
提升GPU内核效率对于推动人工智能系统的发展至关重要。近期研究探索了利用大语言模型（LLM）进行GPU内核生成与优化，但现有方法通常依赖LLM内部隐式学习的启发式规则来决定优化策略，导致试错效率低且优化过程缺乏可解释性。本文提出**KernelSkill**，一种基于双层级记忆架构的多智能体框架。该框架通过协调具备长期记忆（可复用专家技能）和短期记忆（防止重复回溯）的智能体，将隐式启发式替换为知识驱动且感知任务轨迹的专家优化技能。在KernelBench基准测试的1-3级任务中，KernelSkill实现了100%的成功率，并相比Torch Eager分别取得了5.44倍、2.82倍和1.92倍的平均加速比，显著优于现有基线方法。

## 1. 引言
高效的GPU内核是现代AI系统的核心，直接决定了GEMM、卷积和数据移动等基础算子的吞吐量。然而，实现高性能内核通常高度依赖专家经验，需要仔细协调内存访问模式、并行分解、同步机制及对数值敏感的指令选择。传统的专家驱动优化涉及漫长的性能分析引导迭代周期，成本高昂且进展缓慢。

尽管大语言模型为自动化内核优化带来了希望，但现有方法存在明显局限：
1. **基于训练的方法**：需要大量数据 curated 和计算资源，且难以适应实际工程中动态变化的性能分析反馈。
2. **基于推理的闭环优化**：常因优化策略选择不精确而导致低效探索，且决策过程缺乏可解释性，难以复用经验。

本文的核心洞察是：**用知识驱动且感知任务轨迹的专家优化技能替代隐式的模型内部启发式规则**。基于此，我们提出了KernelSkill，一个具有双层记忆增强机制的多智能体框架。

## 2. 核心贡献
- **KernelSkill框架**：提出了一种闭环多智能体架构，协调生成、验证、性能分析、规划和修复等环节，实现迭代式内核优化。
- **双层记忆机制**：
  - **长期记忆**：将大量专家级GPU优化技能蒸馏为结构化、可检索的知识库，支持可复用且可解释的方法选择。
  - **短期记忆**：记录每个任务的优化与修复历史轨迹，稳定多轮 refinement 过程，避免重复错误。
- **卓越的实验表现**：在KernelBench Levels 1–3上，使用ChatGPT-5.1作为基座模型，KernelSkill实现了100%成功率，并分别取得5.44×、2.82×和1.92×的平均加速比，全面超越 prior baselines。

## 3. 方法设计

### 3.1 多智能体优化流程
KernelSmart包含以下关键智能体：
- **Generator**：将PyTorch参考实现转换为初始CUDA内核种子。
- **Reviewer**：由编译器、验证器和性能分析器组成，提供编译状态、正确性及性能反馈。
- **Feature Extractor**：提取静态代码特征（如内存访问模式、向量加载等），辅助方法检索。
- **Diagnoser & Repairer**：在编译或正确性失败时，基于短期记忆生成修复计划并执行。
- **Planner & Optimizer**：在通过验证后，结合长期记忆检索候选优化方法，制定并执行优化计划。

整个流程以闭环方式迭代最多N轮，返回性能最优的内核。

### 3.2 双层记忆架构
#### 长期记忆（Long-term Memory）
- **来源**：从GPU优化文献及工程经验中蒸馏出的专家知识。
- **结构**：
  - **确定性决策策略**：基于性能指标和代码特征，通过规则匹配筛选候选优化方法。
  - **方法知识库**：为每种方法提供原理说明和实现提示，确保决策可追溯、可解释。
- **作用**：实现跨任务的知识复用，减少盲目试错，提升方法选择的准确性。

#### 短期记忆（Short-term Memory）
- **内容**：记录当前任务的优化/修复历史，包括尝试的方法、结果反馈及生成的内核版本。
- **作用**：
  - 防止在多轮迭代中重复无效操作或陷入循环修复。
  - 支持耦合优化的协同应用，提升 refinement 稳定性。

## 4. 实验结果
在KernelBench基准测试（Levels 1–3，共250个任务）上的评估显示：

| 方法          | Level 1 (Success/Speedup) | Level 2 (Success/Speedup) | Level 3 (Success/Speedup) |
|---------------|---------------------------|---------------------------|---------------------------|
| Kevin-32B     | 0.83 / 1.18×              | 0.92 / 1.74×              | 0.46 / 0.32×              |
| STARK         | 1.00 / 3.03×              | 1.00 / 2.69×              | 1.00 / 1.58×              |
| **KernelSkill** | **1.00 / 5.44×**          | **1.00 / 2.82×**          | **1.00 / 1.92×**          |

- **成功率**：KernelSkill在所有级别均达到100%，是唯一与STARK持平但加速比更高的方法。
- **加速比**：相比最强基线STARK，KernelSkill在Level 1提升79.5%，Level 3提升21.5%。
- **消融实验**：移除任一记忆组件均导致成功率和加速比显著下降，验证了双层记忆设计的必要性。

## 5. 结论
KernelSkill通过将专家优化知识外化为可检索的长期记忆，并结合任务特定的短期轨迹记忆，成功解决了现有LLM驱动内核优化中方法选择不准、过程不稳定和缺乏可解释性的问题。其在多个难度级别的任务上均实现了卓越的性能与鲁棒性，为自动化GPU内核优化提供了新的范式。
