
SKILL0: In-Context Agentic Reinforcement Learning for Skill Internalization

https://arxiv.org/pdf/2604.02268


这篇论文提出了一种名为 **SKILL0** 的创新框架，旨在解决大语言模型（LLM）代理在推理时过度依赖外部技能检索（Skill Augmentation）所带来的局限性。该研究由浙江大学、美团（Meituan）和清华大学的研究人员共同完成。

以下是该论文的核心内容介绍：

### 1. 核心痛点与动机
目前的主流范式是在推理时通过检索将“技能”（即自然语言形式的程序性知识）注入模型上下文。这种方法存在三个主要问题：
*   **检索噪声**：检索结果可能包含无关或误导性的信息。
*   **Token 开销**：随着交互轮次增加，注入的技能内容导致上下文长度急剧膨胀，限制了扩展性。
*   **缺乏内化**：模型只是在“执行”提示中的指令，而非真正“学会”了这些技能（知识停留在上下文中，而非模型参数中）。

### 2. 核心方法：SKILL0
SKILL0 是首个将**技能内化（Skill Internalization）**作为明确训练目标的强化学习（RL）框架。其核心理念是：**“训练时有技能，推理时无技能”**。

它包含三个关键技术组件：

*   **情境强化学习 (In-Context Reinforcement Learning, ICRL)**：
    *   在训练阶段，模型可以看到技能作为上下文指导（In-Context）。
    *   在推理阶段，完全移除技能上下文。
    *   通过 RL 优化，迫使模型将技能从“读取”转变为“内化”，从而学会自主行为。

*   **动态课程学习 (Dynamic Curriculum)**：
    *   **渐进式撤除**：训练过程分为多个阶段，技能预算（Skill Budget）线性衰减，直到推理时为零。
    *   **基于效用的筛选**：并非盲目移除，而是根据当前策略（Policy）的“在策略有用性”（On-Policy Helpfulness）动态评估每个技能的价值。只有当前策略仍能从中受益的技能才会被保留，否则被过滤掉。

*   **视觉上下文压缩 (Visual Context Compression)**：
    *   为了解决长上下文 Token 消耗问题，SKILL0 将文本交互历史和技能渲染为紧凑的视觉图像（Visual Tokens）。
    *   模型甚至被训练自我生成压缩率，以平衡任务成功率和上下文效率。

### 3. 实验结果与性能
在 **ALFWorld**（具身任务）和 **Search-QA**（搜索问答）基准测试中，SKILL0 展现了卓越的性能：

*   **超越基线**：相比标准的 RL 基线（如 AgentOCR），SKILL0 在 ALFWorld 上提升了 **+9.7%**，在 Search-QA 上提升了 **+6.6%**。
*   **对抗检索增强方法**：在不使用任何推理时技能检索的情况下，SKILL0 的表现优于或持平于使用技能增强的方法（如 SkillRL）。
*   **极高的上下文效率**：推理时的平均上下文 Token 成本极低（少于 **0.5k** tokens per step），远低于传统的文本基或技能增强方法（通常消耗 2k+ tokens）。

### 4. 总结
SKILL0 成功地将外部技能知识“编译”进了模型的参数中。它不仅消除了推理时对外部技能库的依赖，降低了延迟和噪声干扰，还建立了一种从依赖外部工具向真正自主智能体转变的新范式。
